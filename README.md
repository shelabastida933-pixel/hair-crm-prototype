# 发丝管家

养发馆（白转黑）客户关系管理 · **可用的 H5 版本**

## 🔗 在线地址（手机上直接打开）

**https://shelabastida933-pixel.github.io/hair-crm-prototype/app/**

---

## ✅ 现在真能做什么

| 功能 | 状态 | 说明 |
|---|---|---|
| **📷 拍照上传** | ✅ 真能用 | 点「拍照」调起手机相机，自动压缩到 1400px 存下来 |
| **💾 存储** | ✅ 真能存 | 客户档案 + 照片存在手机本地（IndexedDB），关页面、切 App 都不丢 |
| **📤 分享转发** | ✅ 真能用 | 生成 1080×1580 带店名的效果对比图，可分享/存相册 |
| **今日待办** | ✅ 真能用 | 自动算谁该联系、为什么，按紧急度排序 |
| **客户档案** | ✅ 真能用 | 姓名/项目/疗程进度/间隔天数/备注，增删改查 |
| **导出备份** | ✅ 真能用 | 一键导出 JSON，换手机时导入 |

## ⚠️ 必须知道的两件事

**1. 数据存在这台手机上。** 换手机、清理浏览器数据会丢。
→ 重要数据请定期用「设置 → 导出备份」。

**2. 这是验证版，不是正式产品。**
按 MRD 的判断：**产品成败不在技术，在「老板娘会不会用」**。
所以这一版的目标是——**拿去给养发馆老板娘真机试，看她的反应**，而不是直接上线。

## 🎯 怎么用（给老板娘 3 步）

```
1. 手机浏览器打开上面的地址 → 「添加到主屏幕」（iOS: 分享→添加到主屏幕）
2. 设置里填店名（会印在分享图上）
3. 加客户 → 每次到店点「拍照」→ 拍满 2 张后点「生成效果对比图，发给客户」
```

**核心用法就一句：** 每次客户做完，拍一张；攒够几张，一键生成对比图发给她。

## 🧠 核心洞察（来自 MRD，仍然成立）

### 1. 养发馆卖的不是产品，是「坚持」

白转黑疗程 = 3-6 个月 = 每周到店 1-2 次 = 共 20-50 次。
**客户中途放弃，是这门生意最大的利润漏损。**

### 2. 四个高危流失点

| # | 阶段 | 流失原因 |
|---|---|---|
| 1 | 体验后未成交 | 当场没转化，之后没人跟 |
| 2 | 疗程前 3 次 | 效果滞后，看不到变化 |
| 3 | **疗程中段 1-2 月** | **打卡疲劳，惰性发作** |
| 4 | 疗程结束 | 无复购引导 |

### 3. 痛点不是"不知道要联系"，是"不知道说什么"

**这是整个产品的设计支点。**
从"要不要发这条消息"到"发送"，中间不能超过 2 次点击。

## 🚧 极简硬约束（已落地）

1. 一屏一件事（首屏无导航栏）
2. 字号 ≥ 16px（目标用户 40-55 岁）
3. 按钮高度 ≥ 48px
4. 关键操作用文字不用图标
5. **零录入优先**（拍照即记录，不用填表）
6. 能撤销
7. 不说专业术语
8. 颜色不超 3 种（红/黄/灰）+ 品牌青
