# 发丝管家 · 原型

养发馆（白转黑）客户关系管理系统的可点击原型。

## 🎯 产品定位

> 让一个没精力记事的养发馆老板娘，打开手机就知道今天该联系谁、说什么，并且一键发出。

## 📱 原型入口

| 原型 | 说明 |
|---|---|
| **[主流程](prototype.html)** | 今日待办 / 客户卡片 / 一键发消息 |
| **[效果对比图](compare_poster.html)** | 生成可直接发给客户的对比图 |

## 🧠 核心洞察

### 1. 养发馆卖的不是产品，是「坚持」

白转黑疗程 = 3-6 个月 = 每周到店 1-2 次 = 共 20-50 次。
**客户中途放弃，是这门生意最大的利润漏损。**

### 2. 四个高危流失点

| # | 阶段 | 流失原因 |
|---|---|---|
| 1 | 体验后未成交 | 当场没转化，之后没人跟 |
| 2 | 疗程前 3 次 | 效果滞后，看不到变化 |
| 3 | **疗程中段 1-2 月** | **打卡疲劳，惰性发作** |
| 4 | 疗程结束 | 无复购引导 |

### 3. 痛点不是"不知道要联系"，是"不知道说什么"

**这是整个产品的设计支点。**
从"要不要发这条消息"到"发送"，中间不能超过 2 次点击。

## 🖥 首屏设计

```
今天                    要联系 3 位

🔴 张姐  该做第 4 次护理了    [发消息][已联系]
   上次 9/9 ｜ 已隔 7 天

🟡 李姐  疗程还剩 2 次        [发消息][已联系]
   已完成 10/12 次 ｜ 效果不错

🔵 王姐  体验后 3 天没回复     [发消息][已联系]
   8/29 到店体验 ｜ 未成交
```

**点「发消息」→ 自动生成文案 → 确认发送（共 2 次点击）**

## 🚧 极简硬约束

1. 一屏一件事（首屏无导航栏）
2. 字号 ≥ 16px（目标用户 40-55 岁）
3. 按钮高度 ≥ 48px
4. 关键操作用文字不用图标
5. **零录入优先**（到店打卡自动记时间）
6. 能撤销
7. 不说专业术语
8. 颜色不超 3 种（红/黄/灰）
